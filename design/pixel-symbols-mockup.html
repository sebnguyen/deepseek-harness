Pixel symbols · one 16×16 grid

Render at whole multiples of 16px

The grid is fixed at 16×16. 16, 32, 48, 64, 96 and 128 px all divide it into whole pixels; 18 px does not (1.125 px per cell), which is the softness the old chat mark had. The gap is 32% of each cell in viewBox units — the DigitalOcean mark's recipe — so it stays proportional at every multiple.

Why 18px looked soft

The same read mark, rasterized at its real pixel size and magnified with nearest-neighbour. Only whole multiples land every cell on a whole pixel.

DO mark vs header mark — same 32% gap

Both are 16×16 with a 0.68 cell inset 0.16 on each side: the gap is 0.32 units, 32% of a cell, at every size. The only difference is the corner: the DO mark uses rx 0.17, the header symbols rx 0.10.

Gap scale — 32% of every cell

Each cell is inset 0.16 and drawn 0.68 wide in the 16-unit viewBox, exactly like the DO mark. The gap is a constant fraction of the cell, so it grows with the render size instead of being re-tuned per size.
