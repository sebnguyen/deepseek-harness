One 16x16 grid is derived through the 16x16 coverage window and every face prints it, so the pixel scale is identical at 12px and 168px. Each lit cell is a full 1x1 rect and the 20% gap is a CSS clip-path (inset 10%) on that cell, so the gap scales with the mark instead of being retuned per size. Each of the 16 bucket groups carries its own clockwise stagger on the shared step-end ladder (1.2s), so the light runs around the mark starting at 12 o'clock. fill="currentColor" themes light/dark from CSS color.
