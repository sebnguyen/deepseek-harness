# Bundled typefaces

- `InterVariable.woff2` — Inter, variable (weights 100–900). Copyright 2016
  The Inter Project Authors. SIL Open Font License 1.1; see `OFL-Inter.txt`.
- `JetBrainsMonoVariable.woff2` — JetBrains Mono, variable (weights 100–800).
  Copyright 2020 The JetBrains Mono Project Authors. SIL Open Font License 1.1;
  see `OFL-JetBrains-Mono.txt`.

These are the harness standard: Inter is the UI face (`--dsw-font-family`) and
JetBrains Mono is the code face (`--ds-font-family-code`). The VS Code twin
bundles the same files at `vscode/src/vs/workbench/browser/media/`.
