# dsh-tool-turn-finish

The quiet close, as a catalog tool. Quiet conversation mode promises a
transcript whose closing row is one plain answer; `finish` lets the model says
the work is done and close the turn now, instead of ending on the loop's
natural zero-tool-call stop.

The tool itself only marks the turn complete: under quiet it calls the turn
registry's `concludeTurn` seam at its tool result, outside quiet it records
nothing and the turn carries on. The closing summary is delivered by
conversation-mode: the turn's ordinary close latches one tagged wrap-up turn
whose requests travel with `toolChoice: 'none'` on routes that accept the
field, so the closing answer leaves with no tool surface.

- Tool name: `finish`; no parameters; output `{ recorded: boolean }`.
- Quiet only: reads the calling session's `turnShape` projection at call
  time; a composition without conversation-mode registers the tool inert.
- Standard catalog: row `tool-turn-finish` in the standard agent preset; the
  catalog is generated by `scripts/gen-tool-catalog.ts`.
