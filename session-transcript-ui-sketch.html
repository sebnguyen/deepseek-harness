Vocabulary stays semantic end to end: every proposal keys off durable discriminants (event type, source.kind, the ContextForm vocabulary, tool name, meta) and draws the answer with the existing primitives — DisclosureRow, StateDot, ioCard, TerminalBlock, Inspect pill — because the design already knows how to present each of these shapes.
